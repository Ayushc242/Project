# Spotify Clone (HTML, CSS, JavaScript)

A simple **Spotify Clone** built with **HTML**, **CSS**, and **JavaScript**. This project replicates the basic features of the popular music streaming platform, Spotify, allowing users to play music, search for songs, and view playlists in a simple, user-friendly interface.

---

## Features

- **Music Playback**: Play/pause songs, skip tracks, and adjust volume.
- **Search**: Search for songs and albums (dummy data or mock data).
- **Playlist**: View and switch between different playlists.
- **Responsive Design**: Works on both desktop and mobile devices.

---

## Technologies Used

- **HTML**: For the structure and layout of the pages.
- **CSS**: For styling and responsive design.
- **JavaScript**: For functionality like song playback, search, and interactivity.
